# 麻雀点数計算トレーナー

日本式麻雀（リーチ麻雀）の点数計算を、ブラウザ上で繰り返し練習できる学習アプリです。

役の判定、符計算、翻数計算、最終点数の計算を、実戦に近い手牌を使って練習できます。問題に回答するとすぐに採点結果と解説が表示されるため、間違えた箇所を確認しながら学習を進められます。

HTML・CSS・JavaScriptで構成されており、特別なインストールや外部サービスへの接続を行わず、ブラウザ上で利用できます。

---

## プロジェクトの目的

本プロジェクトは、日本式麻雀の点数計算を効率よく反復練習できる環境を提供することを目的としています。

主に、次の内容を学習できます。

- 手牌から成立する役を判断する
- 手牌の符を計算する
- 役やドラから合計翻数を計算する
- 親・子、ロン・ツモに応じた最終点数を計算する
- 実戦に近い流れで、素早く点数を判断する

麻雀のルールや役を一から網羅的に解説する教材ではなく、すでに基本的なルールを理解している方が、点数計算に慣れるための学習ツールとして設計しています。

## 学習できる内容

本アプリでは、実戦を意識した問題を通して、次の内容を学習できます。

- 手牌から成立する役の判定
- 符の計算
- 翻数の計算
- 親・子、ロン・ツモを含めた最終点数の計算
- 副露・食い下がり・槓ドラを含む実戦的な点数計算

問題を繰り返し解くことで、点数計算の正確性だけでなく、実戦で素早く判断する力を身に付けることを目指します。

## 学習モード

| モード | 概要 |
|---------|------|
| 通常モード | 基本的な点数計算を学習します。 |
| 翻数違いモード | 同じ手牌を使い、翻数の違いによる点数の変化を学習します。 |
| 実戦モード | リーチ宣言やロン・ツモなど、実戦に近い流れで点数計算を練習します。 |
| 問題選択・復習モード | 任意の問題を選択したり、苦手な問題を重点的に復習したりできます。 |

各モードの詳しい操作方法や学習のポイントについては、取扱説明書を参照してください。
