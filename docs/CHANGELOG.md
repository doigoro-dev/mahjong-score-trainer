# CHANGELOG

このファイルでは、麻雀点数計算トレーナーの正式リリースごとの主な変更内容を記録します。

形式は [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/) を参考にし、実際に作成された Git タグ、コミット履歴、各バージョンの README・取扱説明書・開発ロードマップを基に整理しています。

---

## [3.0.0] - 2026-07-25

### テーマ

副露と槓ドラを含む、より実戦的な点数計算への対応。

Version 2で整備した4つの学習モードを維持しながら、チー・ポン・明槓を含む開いた手の問題を追加し、出題・表示・符計算・実戦モード・問題監査を副露対応へ拡張したリリースです。

### Added

- 収録問題数を117問から126問へ拡張
- チー・ポン・明槓を含む副露問題を追加
- 副露情報を表す `openMelds` データ構造を追加
- 副露牌を横向き牌を含む形で表示する機能を追加
- 副露による食い下がりに対応
- 副露した平和形のロン和了など、開いた手の符計算に対応
- 槓子数に応じた槓ドラ・槓裏ドラ表示に対応
- Question Audit Toolへ副露データ形式チェックを追加
- Question Audit Toolの監査項目を13項目へ拡張

### Changed

- 副露問題では立直選択を省略し、立直不可として実戦モードを進行するよう変更
- 副露の有無に応じて、実戦モードのステップ表示と案内文を切り替えるよう改善
- 翻数変化モードで、副露問題に立直・一発・裏ドラが付与されないよう調整
- 暗槓・副露・和了牌を含めた牌枚数検証を改善
- 副露牌を含む手牌レイアウトを、画面幅に応じて調整するよう改善
- パソコン、タブレット、スマートフォンでのレスポンシブ表示を改善
- 問題選択・復習機能を正式な学習手段として取扱説明書内に整理
- READMEをVersion 3.0.0の内容に合わせて全面更新
- 取扱説明書をVersion 3.0.0向けに更新し、`user-manual-version3.html`へ移行

### Quality

- Question Audit Toolを副露・明槓を含む問題データへ対応
- 問題データ、牌構成、副露形式、ドラ表示牌形式の検証を強化
- Playwrightによる画面・操作テストと手動確認を実施
- 自動Playwright GitHub Actionsワークフローを削除し、ローカル実行を中心とする構成へ整理
- 不要となった旧静的データ検証スクリプトを削除

### Release

- `feature/version3` ブランチをPull Request経由で `main` へマージ
- Gitタグ `v3.0.0` を作成
- GitHub ReleaseとしてVersion 3.0.0を正式公開

## [2.10.5] - 2026-07-23

### テーマ

実戦に近い流れで、役・符・翻・最終点数を総合的に練習できるアプリへの拡張。

Version 1の基本的な反復練習を発展させ、リーチ判断、ツモ・ロン、ドラ・裏ドラ、点数入力、自動採点までを一連の流れで練習できる実戦モードを中心に、復習機能と品質保証の仕組みを追加したリリースです。

### Added

- 収録問題数を100問から117問へ拡張
- 実戦モードを追加
- 問題選択・復習モードを追加
- 問題一覧から任意の問題へ移動できる機能を追加
- 間違えた問題を独立して復習できる機能を追加
- リーチする・しないを選択する実戦フローを追加
- ツモ・ロンを含む和了方法の判定フローを追加
- ドラ表示牌・裏ドラ表示牌の表示に対応
- 点数入力による自動採点機能を追加
- 解答時間を計測するタイマー機能を追加
- 一気通貫・三色同順などの新しい役を追加
- 場風・自風に対応
- 暗槓問題と暗槓を含む符計算に対応
- 複数暗槓に対応
- 三槓子に対応
- ドラ・裏ドラ・赤ドラに対応
- 親・子、ツモ・ロン、切り上げ満貫を含む点数計算に対応
- 実戦モードの役なしツモ判定を追加
- 学習状態と復習進捗の復元機能を追加・改善
- Question Audit Tool Version 1.0を新規作成
- 開発ロードマップを追加

### Changed

- 問題データを `app/index.html` から `app/questions.js` へ分離
- アプリケーションロジックを `app/app.js` へ分離
- 復習機能を通常学習フローから独立したモードとして整理
- 解説表示を、成立役・翻数・符・最終点数を確認しやすい構成へ改善
- IndexedDBを利用したセッション保存・復元処理を改善
- 起動時に問題データを検証する処理を追加
- Version 2向けREADMEと取扱説明書へ更新

### Fixed

- 問題 `q101` のデータを修正
- 問題 `q106` の点数および表示内容を修正

### Quality

- Question Audit Toolで次の12項目を監査可能にした
  - 問題ID重複
  - 必須項目
  - 翻数整合性
  - 符整合性
  - 点数カテゴリ整合性
  - 切り上げ満貫整合性
  - 役の翻数合計
  - 役一覧整合性
  - 点数カテゴリ再計算
  - 最終点数表示
  - 牌コード・牌枚数
  - ドラ・裏ドラ形式
- Playwrightによる回帰テストを継続
- GitHub Actionsとリリースチェックリストを用いた品質確認を整備

### Release

- Version 2正式版としてリリース
- Gitタグ `v2.10.5` を作成

## [1.6.0] - 2026-07-20

### テーマ

麻雀点数計算を繰り返し練習できる、基本的なWebアプリの完成。

符・翻・点数を反復して学び、ブラウザを再読み込みしても学習を継続できる基本機能と、公開・テストのための開発基盤を整えた最初の正式リリースです。

### Added

- 全100問の練習問題を収録
- 問題を重複なくランダム出題する機能を追加
- 通常モードを追加
- 翻数変化モードを追加
- 解答と解説を表示する機能を追加
- 最初からやり直す機能を追加
- IndexedDBを利用したセッション保存機能を追加
- ブラウザ再読み込み後のセッション復元に対応
- パソコン・スマートフォン向けレスポンシブ表示に対応
- 利用者向け取扱説明書を追加
- READMEへスクリーンショットと利用方法を追加
- GitHub Pagesでの公開に対応

### Quality

- PlaywrightによるE2Eテスト基盤を追加
- 起動、解答、セッション復元、モード切替、レスポンシブ表示のテストを整備
- 問題データの静的検証スクリプトを追加
- 問題ID、符・翻、切り上げ満貫などのデータ検証を実施
- GitHub Actionsによる自動テストを追加
- Windows向けテスト実行バッチを追加

### Release

- Gitタグ `v1.6.0` を作成
- Version 1.6.0としてGitHub Pages公開用の構成を整備
